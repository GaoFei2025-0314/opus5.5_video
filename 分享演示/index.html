05 / 开始制作

第一条提示词，先说清楚想要什么。

起步提示词 · 分享版

请根据我的资料，制作一条视频：
在你的视角里，我是什么样的人。

资料在：【聊天记录】【笔记】【项目】【头像】

用真实数据和原话，引用标日期并核对。
时长、画面、声音和技术方案由你决定。

先给我看几张关键帧，
确认方向后再渲染整片。

明确目标

它在替谁讲，讲什么。

提供依据

路径、数据、原话。

设置检查点

先看得见，再做完整。

06 / 怎么迭代

每一轮，明确这次要改变什么。

先有一版，再逐步改变声音、画面和风格。

V1

建立故事

文字 + 配乐
先把叙事讲通

V2 — V4

改变声音

女声 → 双声 → 男声
画面基本沿用

V5 — V6

重做画面与节奏

点线面体 → 宏伟版
探索空间与冲击

V7 — V12

探索风格

字 / RPG / 手账 / 水墨
快闪 / 漫画

改动前说清楚：哪些保留，哪些重做。已有版本留着，随时可以比较或回退。

07 / 声音实验

声音，决定是谁在讲这个故事。

配音的检查方法

逐句合成 → 转写回来 → 对照原稿。
多音字、人名、英文单独听一遍。
只重做读错的句子。

旁白响起时给配乐让出空间；使用本人或已获授权的音色。此处片段取自各版相同时间附近，内容不保证逐句对齐。

08 / 风格实验

风格，是一套贯穿全片的规则。

点击画面，查看提示词
09 / 先做选择

拿不准风格，就让同一场景试四次。

“用同一个场景，
出四种风格的样片。”

先比较气质、可读性与故事适配度，
再决定整片的方向。

这一次的选择水墨长卷

城市、江水、留白、朱批，
成为同一套表达语言。

10 / 节奏实验

想要“有冲击”，
就把节奏说具体。

150BPM

V11《快闪》 / 30 帧每秒

12 帧一个节拍
0.2 秒一个八分音符

点 → 线 → 面 → 体
每升一维，加一层音乐；重拍前留出短暂安静。

播放 16 秒片段，观察文字、镜头与重拍的关系。

11 / 继续对话

不必先懂术语，先指出不满意的地方。

先说出感受

再补一条可执行的要求

感受可以作为起点；说清楚哪一段、哪里不对、希望怎样变化，下一轮就更容易判断。

12 / 轮到你了

选一种表达，带走一条提示词。

你想让它怎样讲？

路径只用于生成文字，不会读取或上传文件。

可直接修改 / 复制到 Claude Code
13 / 带回去试试

今天回去，先做一支小样。

01

留下能讲出故事的原话。

02

个人回顾、项目故事，
或写给未来的自己。

03

先看关键帧

需要判断节奏时，

04

方向对了再做整片。

你负责判断「像不像你」，让 AI 去完成下一轮尝试。
