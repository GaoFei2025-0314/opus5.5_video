## 如何使用

打开文章，选择喜欢的风格，把提示词中 `【】` 标记的内容替换成自己的资料路径或信息，再交给 Claude Code 尝试制作。

成片演示：[B 站视频](https://www.bilibili.com/video/BV1t4pL6JEoR/)。

## HTML 文章复制到飞书

`add-feishu-copy.py` 为已导出的独立 HTML 添加「复制到飞书」按钮和目标文档入口，`copy-to-feishu.js` 是内嵌的交互代码。二者与文章一起维护，生成的 HTML 继续放在被忽略的 `out/`；重复运行会更新同一个工具栏。目标文档链接只注入本地成品，不写入仓库源码。

```sh
python3 公众号文章/add-feishu-copy.py \
  --html /绝对路径/out/meetup-24/meetup-24.html \
  --feishu-url 'https://你的企业.feishu.cn/wiki/你的文档'
```

点击「复制到飞书」，再打开目标文档，将光标放在正文中，按 ⌘V / Ctrl+V。复制使用 `text/html` 与 `text/plain` 两种格式，保留图片原始内嵌数据、GIF 和链接，移除阅读、放大和复制控件；布局转成适合文档的单列。它不直接修改飞书，也不需要飞书 API 凭证。

浏览器不支持 Clipboard API 或拒绝写入时，会尝试传统复制，再提供可选中全文的手动复制窗口。只有剪贴板写入成功才显示「已复制」。文章图片较多，粘贴后需要等待飞书处理，并检查 GIF 是否显示；接收端的图片上传、动图播放和样式保留需要在实际飞书会话中验收。
