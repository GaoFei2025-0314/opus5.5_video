# 在 AI 眼里，我是什么样的人？

这个仓库收录了公众号文章《我让 AI 给我拍了 12 支短片，讲「在它眼里，我是什么样的人」》的配套资料。

文章记录了我用 Claude Code，根据聊天记录、笔记和项目制作个人短片的过程，整理了 12 个版本的提示词、风格说明和成片截图，涵盖文字动画、像素 RPG、水墨、快闪、漫画等风格，供大家阅读和参考。

## 如何使用

打开文章，选择喜欢的风格，把提示词中 `【】` 标记的内容替换成自己的资料路径或信息，再交给 Claude Code 尝试制作。
