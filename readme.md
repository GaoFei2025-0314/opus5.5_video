# 在 AI 眼里，我是什么样的人？

这个仓库收录了公众号文章《我让 AI 给我拍了 12 支短片，讲「在它眼里，我是什么样的人」》的配套资料。

文章记录了我用 Claude Code，根据聊天记录、笔记和项目制作个人短片的过程，整理了 12 个版本的提示词、风格说明和成片截图，涵盖文字动画、像素 RPG、水墨、快闪、漫画等风格，供大家阅读和参考。

## 如何使用

打开文章，选择喜欢的风格，把提示词中 `【】` 标记的内容替换成自己的资料路径或信息，再交给 Claude Code 尝试制作。

成片演示：[B 站视频](https://www.bilibili.com/video/BV1t4pL6JEoR/)。

## 目录结构

- `公众号文章/`：文章、提示词、配图与 HTML 导出辅助脚本；[飞书复制按钮说明](公众号文章/readme.md#html-文章复制到飞书)。
- `分享演示/`：本次分享的 HTML 交互演示与素材。
- `创作解说/`：第一人称解说文案、个人音色配音工具与影片剪辑程序。
- `build/`、`out/`：被忽略的本地音频、字幕、缓存与成片；个人音色合成结果保留本地，不上传到 Git。

既有中文目录和文档名作为兼容路径保留，新增工程文件使用 ASCII。目录职责同时维护在 `.claude/tidy.json`。原始素材和已验收音频的本地保留策略见 `创作解说/README.md`。
